# ArtViSiON STUDIO — Luxury Brand, Advertising & Retail Production Design

Single-page portfolio site of **Ranjan (Rj) Sarkar**, Creative Lead — 12+ years of retail
production design, branding, advertising and turnkey execution from **Indore, Madhya Pradesh**.

## What is inside
- `index.html` — the complete site (fonts, owl emblem and ambient audio engine embedded;
  no framework, no build step, no external requests — open the file and it works)
- `audio/` — 10 ambient scene soundscapes (s01–s10.mp3) used by the guided studio tour

## Typography (premium luxury system, fully embedded)
- **Playfair Display** (variable 400–900, roman + italic) — all headings, hero, plates
- **Montserrat** (variable 100–900) — body, buttons, kickers, labels, chips, micro-copy
- Both subset to Latin + symbols and embedded as base64 woff2 — zero network fonts

## Site highlights
- Intro choreography: elements appear one-by-one (ON backdrop → owl → STUDiON → button →
  tagline → note → CTA fanfare → tools land sequentially)
- PATHS · CHOOSE YOUR ROUTE (plate-styled heading, after the engineering plates):
  "First, tell us — who are you?" → 🏪 Shop / 🚀 Startup / 🏢 Corporate — panel switches
  instantly, enquiry form's "You are" field syncs automatically

- Enquiry — "Let's Create Your Brand": 103-service selector, budget slabs, LIVE WhatsApp
  message preview, validation, one-tap send to +91 90090 01551

## Deploy on GitHub Pages
1. Create a repository (e.g. `ArtViSiON_STUDiON`)
2. Upload `index.html`, `README.md` and `audio/` to the `main` branch
3. Settings → Pages → Source: `main` / root → Save
4. Site goes live at `https://<username>.github.io/<repo>/`
