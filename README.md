# ∞ STUDiON — ArtViSiON PRODUCTion · DESiGN

Luxury single-page portfolio website — 102 A-to-Z services + 240 sector scenes in 7 RGB/CMYK colour blocks, with a professional voiceover tour, soft ambient music, an Indian-instrumental + nature intro soundscape, typewriter captions, A-to-Z progress scale with car, and turnkey project details.

## Deploy on GitHub Pages (2 minutes)

1. Upload **index.html** and the **audio/** folder (both together) to your repository **root** — or into a `/docs` folder.
2. Repo → **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` → folder `/ (root)` (or `/docs`) → **Save**.
3. Wait ~1 minute, then open `https://<username>.github.io/<repo>/` and press **▶ LET'S CREATiON**.

> ⚠️ `audio/` must sit next to `index.html` — the 10 voiceover MP3s are the only external files. Fonts, owl mascot and logo are embedded inside the HTML (base64).

## Good to know

- Browsers block autoplay sound without one tap — the intro starts sound on the first touch/click/keypress anywhere (a "RELAX TOUCH" hint appears if needed).
- The guided tour has 10 voiceover stops with typewriter captions + soft typing sounds; music ducks under the voice automatically. Scroll/touch anytime to take over control.
- Works on all devices; mobile gets a bottom call/WhatsApp bar.
